# らーく印刷 v0.3.3 リリースノート

## 概要
依存パッケージを最新の安定版に更新しました。ビルドツールチェーンに含まれる setuptools の既知の脆弱性を解消し、その他のライブラリも最新版に追随しています。

## セキュリティ修正

- **setuptools を 83.0.0 に更新**
  vendored された `jaraco.context` 経由のパストラバーサル脆弱性（CVE-2026-23949）を解消しました。旧バージョン（80.10.2）はこの脆弱性の修正前の版でした。

## 依存パッケージ更新

- PyMuPDF: 1.26.7 → 1.28.0
- PySide6 / PySide6-Addons / PySide6-Essentials / shiboken6: 6.10.2 → 6.11.1
- pyinstaller: 6.18.0 → 6.21.0
- pyinstaller-hooks-contrib: 2026.0 → 2026.6
- pywin32: 311 → 312
- packaging: 26.0 → 26.2

機能面の変更はありません。

## アップグレード方法

インストーラー（`RakuPrint_Setup_0.3.3.exe`）を実行してください。既存の設定はそのまま引き継がれます。
