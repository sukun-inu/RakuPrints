# らーく印刷 v0.2.9 リリースノート

## 概要
- 通信まわりを企業内 SSL プロキシー環境に強い実装へ更新しました。
- プレビュー機能を全面見直しし、別ウィンドウ中心の高速プレビュー体験に刷新しました。

## 主な変更点
- `python-certifi-win32` を導入し、Windows 証明書ストアと連携した HTTPS 通信に対応。
- 更新確認 / リリースノート取得 / 更新ダウンロードの通信処理を共通化して安定性を改善。
- プレビュー列（中央カラム）を廃止し、プレビューは別ウィンドウ表示に統一。
- プレビューは起動時デフォルト OFF。必要時のみ表示する動作へ変更。
- プレビュー UI をレスポンシブ化し、描画とキャッシュを最適化して体感速度を改善。
- プレビュー項目のダブルクリックで全画面表示に対応（クリック / Esc / Enter / Space で解除）。
- 全画面プレビューはライト / ダーク共通で「黒背景 + 白文字」表示に統一。
- PDF だけでなく、Word / Excel / PowerPoint もプレビュー可能に拡張（Office から一時 PDF 化して表示）。

## 改善・修正
- 全画面プレビュー時のクラッシュ要因を抑制（スレッド停止処理を安全化）。
- ダークモード時に見づらかったプレビュー内テキスト色を調整。

## 補足
- Office ファイルのプレビューには、対応する Microsoft Office がインストールされている必要があります。
- 既存の印刷フロー・設定項目（PDF/Excel オプション、ルール、更新機能）は従来どおり利用できます。
