# らーく印刷 v0.1.7 リリースノート

## 概要
- About 画面から GitHub のリリースノートを参照できるようになりました。
- プリンターの用紙サイズを自動収集し、プリンター単位で 1 時間キャッシュ更新するようにしました。

## 主な変更点
- 印刷時に「プリンター対応サイズ」および「ドキュメントの用紙サイズ一致」を事前に検証し、不一致はエラー表示します。
- Excel の向き判定を複数シートで正しく集計するよう修正しました。
- 設定読み込み時の `copies` の異常値（0/負数）をクランプしました。
- プリンター変更で用紙サイズが非対応の場合、既定に自動復帰するようにしました。

## 影響
- 用紙サイズが合致しない場合は印刷が止まります。サイズ指定の見直しが必要になることがあります。
- GitHub への接続がない環境ではリリースノート取得に失敗します（エラーメッセージ表示）。

## 更新方法
- いつものインストーラーで上書きインストールしてください。
