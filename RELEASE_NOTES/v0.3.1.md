# らーく印刷 v0.3.1 リリースノート

## 概要
自動アップデート機能のセキュリティを強化しました。ダウンロードしたインストーラーの整合性を SHA256 ハッシュで検証する仕組みを追加し、改ざんされたファイルが実行されないよう保護します。

## セキュリティ修正

- **インストーラーの SHA256 ハッシュ検証を追加**
  自動アップデート時にダウンロードしたインストーラーを、GitHub リリースに同梱の `SHA256SUMS.txt` と照合します。ハッシュが一致しない場合はインストールを自動中止します。チェックサムファイルが存在しない場合は警告を表示してユーザーが判断できるようにしています。

- **インストーラー起動時の `shell=True` を除去**
  不要な `shell=True` オプションを削除し、プロセス生成をより安全な方式に変更しました。

- **更新通知タイムスタンプの保存先を変更**
  一時フォルダー（`%TEMP%`）への書き込みをやめ、アプリ専用フォルダー（`%LOCALAPPDATA%\RakuPrint\`）に変更しました。他プロセスからの干渉を防ぎます。

## ビルド改善

- `SHA256SUMS.txt` をビルドスクリプトで自動生成するようにしました。
- ビルド前に仮想環境とインストーラースクリプトの存在確認を追加しました。

## アップグレード方法

インストーラー（`RakuPrint_Setup_0.3.1.exe`）を実行してください。既存の設定はそのまま引き継がれます。
